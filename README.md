# Nettside for snømåking (prototype)

- `index.html` – forside med priskalkulator og bestillingsskjema. Firmanavn, telefon og prismodell endres øverst i `<script>`.
- `maal.html` – kunden måler innkjørsel, gangvei, terrasse osv. på flyfoto (Kartverket).
- `foresporsel-format.md` – dataformatet for forespørsler, som agenter og dashbord skal bruke.

Skjemaet lagrer foreløpig bare i kundens nettleser. Det må kobles til et sted du kan lese forespørslene før siden tas i bruk.
